# وكيل Repo Init — وصف المهمة

## المهمة
إنشاء مستودع GitHub (repo) جديد لمشروع Wasel Nalut، مع هيكل أساسي وملف README.md.

## الخطوات
1. إنشاء repo على GitHub باسم `wasel-nalut`.
2. إنشاء `README.md` و `gitignore`.
3. إنشاء الـ directories الأساسية:
   - `backend/`
   - `flutter_mobile_app/`
   - `flutter_driver_app/`
   - `logistics/`
4. ربط GitHub Actions بسيط للـ CI.

## التسليم
- رابط GitHub Repo.
- رابط README.md.

## الملاحظات
- يفضّل أن يكون repo خاصاً أو عاماً حسب إعدادات المنظمة.
- يجب إضافة GitHub Actions workflow لأول build.
